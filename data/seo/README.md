# מרשם בעלות SEO

`ownership-registry.json` הוא מקור האמת לבעלות על כוונות חיפוש וכתובות באתר. הוא כולל 14 כתובות ודפוסי כתובות חיים שנמצאו במקור ובבדיקות, וכן 13 עמודי אב ארציים הבאים בתור.

כל רשומה קובעת:

- כוונת חיפוש ראשית אחת
- בעל קנוני אחד
- מזהי ישויות גאוגרפיות קנוניים לנושא העמוד
- עמוד אב ושרשרת פירורי לחם מלאה
- סוג ישות, קהל ותפקיד במשפך
- קצב רענון ומדיניות אינדוקס
- כוונות שאסור לעמוד לקחת מבעלים אחרים
- מקור שמסביר מדוע הכתובת נמצאת במרשם

כתובת החיפוש `/?s={query}` היא דפוס ציבורי נפרד עם `noindex`, אך הבעל הקנוני שלה הוא עמוד הבית. מקטעים שמתחילים ב-`#`, קובצי נכסים, כתובות ניהול, קנרי פרטי, אנליטיקה, כתובות עדכון וכתובות דמה אינם עמודי SEO ולכן אינם רשומות.

## כללי עריכה

1. מוסיפים בעל כתובת לפני יצירת עמוד חדש או קישור ציבורי חדש.
2. לא משייכים אותה כוונת חיפוש ראשית לשתי כתובות.
3. כל עמוד אב וכל כתובת שמקבלת כוונה מוחרגת חייבים להופיע במרשם.
4. שרשרת פירורי הלחם מתחילה ב-`/`, מסתיימת בכתובת הרשומה, והחוליה שלפני האחרונה היא עמוד האב.
5. עמוד חיפוש, API ומשטחים טכניים אינם מקבלים בעלות על שאילתות עריכתיות.
6. אין להשתמש בתווי U+2013 או U+2014. במידת הצורך משתמשים במקף ASCII רגיל.
7. `subject_entity_ids` מפנה רק למזהים שנגזרים ממקורות הגאוגרפיה. עמוד ארצי משתמש ב-`geo:th:country`, ועמוד שאינו עוסק במקום מסוים משתמש במערך ריק.

## בדיקה

הסכמה כתובה ב-`ownership-registry.schema.json`. הבדיקה אינה דורשת חבילה חיצונית: היא מאמתת את JSON מול מילות המפתח שבהן הסכמה משתמשת, בודקת את כללי הבעלות וההיררכיה, וסורקת שוב את כתובות המקור.

```powershell
python tests/seo-ownership-registry.test.py
```

המרשם אינו חלק מחבילת התוסף ואינו משנה את התצוגה הציבורית. הוא מיועד להנחות מחקר, כתיבה, קישורים פנימיים, פירורי לחם וקנוניקל לפני הרחבת התוכן.
