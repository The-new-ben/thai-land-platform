== Description ==

Version 0.1.0 is a bounded bootstrap release. It registers a public release
healthcheck and performs no database, content, theme, rewrite, user, or remote
service mutation. The vendored update UI fallback stays disabled until this
canary has passed on the production PHP 7.4 runtime.
